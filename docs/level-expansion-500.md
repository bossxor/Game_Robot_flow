# 레벨 확대와 UI 배치 미리보기

2026-10-09 후속 소스 수정. 기존 1~200 데이터를 유지하고 201~500을 추가했다. 앱의 메인과 스테이지 화면에는 전체 개수를 표시하지 않는다.

- 일반 보드 48×48, 튜토리얼 2개는 20×20.
- 500개 보드의 블록 배치·색 조합이 서로 다름. 기존 10가지 그림 테마와 팔레트·외곽·작은 장식 변형으로 구성하며 500개의 서로 다른 그림 주제는 아님.
- 모든 색의 컨테이너 재고 합계가 해당 색 블록 수와 일치.
- `LevelLoader.TOTAL`을 500으로 변경하고 저장 진행도·다음 스테이지 해금·이전 저장 가져오기에서 같은 상수를 사용. 저장 초기화 없음.
- 초기 레벨 확대 요청에서는 소스만 수정. 이후 사용자의 설치·커밋·푸시 요청으로 v0.6.0을 적용했다. [최신 검증 기록](v06-validation.md)

## 검증 결과

- 네이티브 규칙 검증 1,058개 assertion 통과.
- 중장비 출격 확률 0과 1 각각 500/500 레벨 완주.
- 500개 보드 데이터 중복 없음, 색별 재고 합계 일치.
- Android 빌드 및 Lint 통과. 오류 0개, 기존 경고 15개.
- 생성 APK의 레벨 500개 포함 확인. WebView와 웹 실행 파일 없음.

## 미리보기

`scripts/preview-layout.py`는 실제 레벨 JSON과 `GameLayout.java`의 카드 치수, UI 팔레트를 기준으로 정적 PNG를 만든다. Pillow가 필요하다.

- 출력: `artifacts/preview/layout-stage-003.png`, `layout-stage-248.png`, `layout-stage-500.png`
- 전체 비교: `artifacts/preview/robot-flow-layout-preview.png`
- 보드와 대기열은 실제 데이터 사용. 첫 두 열에서 한 개씩 선택한 배치를 예시로 표시. 상단 활성 5자리의 나머지 빈 위치는 기존 요청대로 숨김.
- 로봇·트럭·아이템은 배치를 이해하기 위한 간략 그림이며 실제 OpenGL 렌더링 캡처가 아님. 움직임과 선택 피드백은 정적 이미지에 포함되지 않음.
