# Robot Flow v0.6.0 검증 — 2026-10-09

## 변경

- 500개 레벨. 튜토리얼 2개 20×20, 일반 보드 48×48. 앱에서 총 개수 숨김.
- 정사각형 컨테이너, 큰 숫자, 선택 시 위쪽 활성 5칸 이동, 동일 열 상승. 작업 공간 추가로 최대 6칸. 별도 공용 트럭은 20개 적재 후 출발.
- 크림·차콜·오렌지 UI, 프레임과 카메라 비율 조정, 원형 아이템 4개. 두 종류의 로봇과 7색 테마 유지.
- 기본 시뮬레이션 속도는 이전 2×. 새 배속 2×는 기본의 두 배.
- 웹앱은 같은 레벨 JSON과 새로운 UI 사용. 브라우저 Canvas 표현이며 APK는 Java/OpenGL 3D 유지. 기존 localStorage 저장 읽기와 아이템 무제한 On/Off 이스터에그 포함.

## 확인

- 네이티브 엔진 500개 레벨, 중장비 출격 확률 0/1 각각 완주. 1,058개 assertion 통과.
- Android `assembleDebug lintDebug` 성공. Lint 오류 0개, 기존 경고 15개.
- APK에 레벨 500개 포함. WebView와 HTML/JavaScript/CSS 실행 파일 없음.
- 웹의 레벨 500개 재고·형식·중복 검증, 튜토리얼 2조건 완주, 큰 보드 컬러 제거·트럭 출발 완료·중복 적재 방지, 이전 진행도와 무제한 모드 저장 검증 통과.
- 기존 프로토타입 회귀 테스트 213개 통과. 새 웹 구성 테스트 5개 통과.
- 브라우저에서 컨테이너 선택·열 상승, 일시정지 아이콘 패널과 설정, 설정 제목 7회 터치 On/Off, 원래 수량 3/2/3/3 복귀 확인. 콘솔 오류 없음.
- 정적 웹 빌드 생성, localhost:5173 실행. GitHub Pages 배포 설정은 없음.
