# RoboRelay v0.9.3 — 컬러 제거 확대 선택

블록 수와 일반 화면의 시야는 유지합니다. 1~2 스테이지는 20×20, 400개이고 일반 스테이지는 48×48, 2,304개입니다. 기본 보드 폭은 화면의 약 76.2%이며 세로 화면이 짧으면 전체 필드를 담도록 거리를 조절합니다. Colony Flow 참고 이미지의 비슷한 블록 밀도·프레임 비율을 기준으로 유지하며 원작의 정확한 레벨별 데이터와 같다고 보장하지는 않습니다.

컬러 제거 아이템을 선택하면 게임 진행을 잠시 멈추고 카메라를 부드럽게 1.6배 확대합니다. 보드를 드래그해 가장자리 색까지 선택할 수 있습니다. 드래그는 선택으로 처리하지 않습니다. 탭 좌표를 실제 확대·이동한 카메라로 되돌려 블록 색을 판별합니다. 성공하거나 같은 아이템을 다시 누르거나 다른 아이템으로 전환하면 진행을 재개하고 기본 시야로 돌아옵니다. 취소·빈칸 탭·드래그에는 아이템을 소비하지 않습니다.

Android에서 선택용 카메라는 로봇 출격 위치, 트럭 길과 포털의 기본 좌표를 변경하지 않습니다. 웹 미리보기에도 동일하게 적용합니다. 기존 한 스테이지의 컬러 제거 사용 제한과 무제한 모드 규칙은 유지합니다.

버전은 0.9.3, Android versionCode는 16입니다. 카메라의 확대/복귀, 드래그 제한, 좌표 역변환을 통한 실제 블록 선택을 테스트합니다. 실제 기기에서의 화면·드래그 감각은 별도 확인이 필요합니다.
