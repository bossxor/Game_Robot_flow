# Robot Flow UI·게임 규칙 v0.7.1

2026-10-09 사용자 확정 요청을 기준으로 한 현재 구현. 디자인 수정은 이 문서를 우선하고, 구도 참고는 `colony-ui-reference.md`, 기존 아트 방향은 `construction-redesign-plan.md`를 함께 봅니다.

## 배치와 선택

- 기본 작업 공간 5개를 항상 표시. 선택한 컨테이너가 빈칸으로 이동하며 컨테이너 바로 앞에 로봇이 나타나 걸어갑니다. 컨테이너 위 출격 그림·표시등·문 모션은 없습니다. 선택 취소는 없습니다.
- 대기열은 평면 4열, 일반 화면 4행·긴 화면 5행. 작은 화면은 가용 높이에 맞춰 줄입니다. 세로 스와이프로 다음 행을 확인하며 소진된 열은 위로 당겨집니다.
- 같은 행에 연결 표시가 있는 컨테이너는 함께 선택. 전부 맨 앞이며 전체가 빈칸에 들어가야 합니다. 슬롯 부족 시 부분 선택하지 않습니다.
- 마지막 빈칸을 현재 회수할 색이 없는 컨테이너로 채우려는 경우 붉은 테두리로 안내하며 선택은 허용합니다.

## 로봇·트럭·현장

- COURIER와 BUILDER 두 모델, 각각 7색 외장. 기본 운반원 약 1.6배 확대, 중장비 약 1.52배 확대. 보드 폭에 비례하는 월드 스케일로 20×20/48×48에서도 화면상 크기를 비슷하게 유지합니다.
- 한 번에 하나씩 출격. 전역 출격 간격 0.52 시뮬레이션 초(기본 1×의 실제 약 0.26초), 컨테이너마다 최대 4기 동시 작업. 출구 모션 없이 걷기·회전·집기·운반·탑승.
- 트럭은 작업 공간과 독립. 20개 적재 후 화면 밖으로 출발. 최대 3대가 이미 대기하다 앞으로 이동합니다. 마지막 화물은 부분 적재 출발이며 남은 실제 운반량이 줄면 대기 트럭 수도 줄어듭니다.
- 크레인과 장식을 게임 보드 위에 겹치지 않게 배치. 오전·노을·밤 배경을 10개 스테이지 구간마다 순환. 메인은 로봇 두 모델과 움직이는 트럭 한 대의 디오라마. 왼쪽 고정 대기 트럭은 제거.

## 아이템

- 공간 추가: 누르는 즉시 사용, 최대 6칸.
- 컬러 제거: 아이콘을 누르고 보드 블록 터치. 터치한 블록 색 전체 제거. 별도 색상 창 없음.
- 셔플: 누르는 즉시 사용. 묶음 규칙 유지.
- 꺼내기: 아이콘을 누르고 뒤쪽 컨테이너 터치. 연결 묶음 전체를 각 열 앞으로 이동.
- 선택형 아이템 아이콘을 다시 누르면 대상 선택 모드를 닫습니다. 이는 출격 컨테이너 선택 취소가 아닙니다.
- 숨겨진 무제한 On/Off는 기존 설정 제목 7회 터치 규칙 유지. On 사용은 보유 수량을 차감하지 않습니다.

## 진행과 보상

- 일반 NORMAL, 5의 배수 HARD, 10의 배수 SUPER HARD. HARD는 2개, SUPER HARD는 최대 3개 연결 묶음을 넣어 작업 공간 판단을 추가합니다. 생성 시 같은 깊이·같은 색을 연결하여 해법을 보존합니다.
- 대기 컨테이너가 5개 이하(0개 포함)이며 현재 빈칸에 모두 들어가면 합법 선택을 자동 완료하고 마지막 작업을 5×로 진행합니다. 기본 1×=이전 2×는 유지하며 수동 배속은 1→2→3→4→1 순환합니다.
- 신규 스테이지 연속 완료 시 기본 보상 외 10/20/30/40/50코인 추가. 재플레이는 연승 보너스 없이 기존 축소 보상. 실패·중도 종료·미완료 재시작은 연승 초기화.
- 완료 로봇 연출 뒤 결과창 표시. 앱에는 전체 레벨 개수를 표시하지 않습니다.
