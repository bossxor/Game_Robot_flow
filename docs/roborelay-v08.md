# RoboRelay v0.8 — 기본 난이도 조정

Robot Flow의 새 표시 이름은 **RoboRelay(로보릴레이)**입니다. Android 런처·메인 로고, 웹 제목·메인·설치 메타데이터, 프로젝트와 APK artifact 이름을 변경했습니다. 기존 앱 ID `com.bossxor.robotflow`와 저장 키는 유지해 업데이트 시 진행 기록을 이어갑니다.

## 난이도 기준

Colony Flow의 공식 [게임 설명](https://play.google.com/store/apps/details?id=com.abi.colony.flow)처럼 5개 슬롯, 색상별 작업, 앞쪽 상자 선택과 선택 순서로 생기는 교착을 중심으로 조정했습니다. 정확한 원작 레벨 데이터나 승률을 확보한 것은 아니므로 체감 난이도는 기기 플레이로 추가 조정해야 합니다.

기존 대기열은 블록을 지울 수 있는 순서를 그대로 4열에 나눠 NORMAL에서 선택의 부담이 작았습니다. 새 대기열은 그림과 색상별 로봇 총량을 보존하면서 안쪽에 갇힌 색을 일찍 노출합니다. 아직 길이 없는 색을 연속 선택하면 슬롯을 점유하고, 바깥쪽을 처리해 길을 열면 다시 작업합니다. 존재하지 않는 색이나 잉여 로봇을 추가하지 않습니다.

| 난이도 | 안쪽 색 상자의 조기 노출 | 묶음 작업 |
| --- | --- | --- |
| 첫 레벨 | 2개, 슬롯 관리 소개 | 없음 |
| NORMAL | 5개 | 없음 |
| HARD, 5의 배수 | 7개 | 같은 색 최대 2개 |
| SUPER HARD, 10의 배수 | 9개 | 같은 색 최대 3개 |

모든 난이도에서 기본 슬롯은 5개입니다. 조기 노출 상자 위치는 레벨별로 바꾸고, 해당 열에도 이후 작업 상자를 배치합니다. 레벨의 그림·크기·보상, 아이템과 운반 규칙은 유지합니다.

## 구현 및 검증

`src/queue-planner.js`와 Android `QueuePlanner.java`는 기존 JSON을 불러온 뒤 같은 변환을 적용합니다. 그림 JSON 500개를 복사해서 수정하지 않고 웹과 Android에 같은 규칙을 적용합니다. `queueVersion`으로 같은 레벨에 중복 변환하지 않습니다.

검증은 500개 레벨의 색상별 총량·변환 재현성·Java/JavaScript 대기열 일치, 2~500 레벨에서 안쪽 색 5개를 먼저 선택했을 때의 교착, 기본 로봇과 게이지 보너스 각각의 아이템 없는 완주를 포함합니다. 기기 UI와 원작 대비 체감 난이도는 별도의 플레이 확인이 필요합니다.

GitHub 저장소의 제안 이름도 `RoboRelay`입니다. 연결 도구에 저장소 이름 변경 기능이 없어 저장소명 변경은 코드 변경과 별도로 GitHub Settings → General → Repository name에서 진행해야 합니다. 이름 변경 전까지 README의 저장소 링크는 기존 주소를 유지합니다.
