# RoboRelay v0.9.2 — 두꺼운 두 색 연결선

묶음 컨테이너 사이의 연결선을 기존 4px 크림색에서 논리 좌표 기준 12px(카드 폭의 ¼)로 키웁니다. 어두운 외곽과 밝은 하이라이트를 더하고, 연결 경로 길이의 정확한 절반까지 각 컨테이너 색으로 표시합니다. 같은 색끼리 연결되면 선도 같은 색입니다.

실제 group을 기준으로 가로·세로·떨어진 묶음을 연결합니다. 3개 이상은 가장 가까운 짝을 이어 불필요한 중복선을 줄입니다. 같은 행/열에서 떨어진 짝은 카드 위쪽/오른쪽으로 우회하며, 위 여백이 없는 작업 슬롯에서는 아래쪽으로 우회합니다. 대기열·위 작업 슬롯·로켓 이동 중 모두 현재 위치를 기준으로 그립니다. 화면에 보이는 묶음 멤버만 연결하고, 작업을 마쳐 사라진 컨테이너로 향하는 선은 제거합니다.

Android와 웹에 적용하며 게임의 묶음 선택 규칙은 유지합니다. 버전은 0.9.2, Android versionCode는 15입니다. 웹 연결선 테스트는 가로·세로, 비인접 짝, 서로 다른 묶음, 3개 연결 및 색 분할의 절반 길이를 확인합니다. 실기기 화면은 별도로 확인해야 합니다.
