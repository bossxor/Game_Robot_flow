# RoboRelay v0.9.1 — 컨테이너 로켓 이동

대기열에서 위 작업 슬롯으로 선택한 컨테이너를 로켓처럼 운반합니다. 짧은 출발 압축, 주황·노랑 추진 불꽃, 이동 방향에 따른 기울기와 곡선 상승, 가벼운 착지 압축을 420ms 동안 보여줍니다. 일반적인 대기열의 중앙 이동은 기존 280ms 모션을 유지합니다.

Android Canvas와 웹의 전용 이동 레이어에 적용합니다. 묶음 선택은 각 컨테이너를 함께 이동시킵니다. 실제 시간으로 재생하고 이동용 컨테이너 사본을 유지해 마지막 10배속이나 숫자 갱신으로 모션이 중간에 사라지지 않게 합니다. 웹에서 메인·재시작·다음 스테이지로 이동하면 진행 중인 모션을 정리합니다. Android 애니메이션 비활성화 및 웹의 reduced-motion 설정에서는 로켓 모션을 생략합니다.

게임의 선택·로봇 출격·작업 완료 규칙과 배속은 유지합니다. 버전은 0.9.1, Android versionCode는 14입니다. 실기기에서 모션의 화면 배치와 체감은 아직 확인하지 않았습니다.
