# RoboRelay v0.9 — 둥근 메인과 컨테이너 정렬

첨부된 Colony Flow 화면의 볼록한 버튼, 밝은 숫자와 제한된 컨테이너 열을 참고해 로봇 테마의 UI를 개선했습니다. 참고 이미지의 캐릭터나 자산을 가져오지 않고 기존 3D 모델·Canvas·SVG를 수정합니다.

## 메인

- 민트 하늘·라임 받침대, 보라색 스테이지 배지, 초록색 볼록한 플레이 버튼
- 더 둥근 로봇 메시, 표면 하이라이트, 큰 눈과 볼·손을 흔드는 동작
- 흰 테두리와 입체 그림자가 있는 둥근 메뉴 버튼과 로고

## 컨테이너

색상을 선명하게 하고 두꺼운 외곽선의 숫자, 윗면 하이라이트, 흰 받침대를 적용합니다. 세 자리 숫자는 카드 안에 맞춥니다. 뒷줄도 색과 숫자를 읽을 수 있도록 약하게만 어둡게 표시합니다.

대기열은 행마다 따로 중앙 정렬하지 않고 **남은 열 전체**를 중앙 정렬합니다. 한 열의 컨테이너를 모두 사용하면 해당 열만 제거하고, 남은 열을 280ms 동안 중앙으로 이동합니다. 3열 → 2열 → 1열에서 모든 행의 같은 열이 계속 수직으로 맞습니다. 짧은 열은 빈칸을 남겨 다른 열이 잘못 연결되어 보이지 않게 합니다. 각 열의 앞 컨테이너를 사용하면 그 열의 다음 컨테이너가 위로 올라옵니다. Android 터치 범위도 애니메이션 중 실제 카드 위치를 따라갑니다.

## 마지막 작업

남은 컨테이너가 5개 이하이고 모두 빈 작업 슬롯에 들어갈 때 자동 출격하는 기존 조건은 유지합니다. 마무리 재생 속도와 배속 표시·안내를 **5배 → 10배**로 바꿉니다. 웹과 Android에 모두 적용합니다.

앱 버전은 0.9.0, Android versionCode는 13입니다. 앱 ID와 저장 키, 레벨·난이도·아이템 규칙은 유지합니다. 검증은 빈 중간 열 제거, 길이가 다른 열의 정렬, 빈 대기열, 기존 네이티브 규칙과 웹 테스트 및 Android 빌드·린트를 포함합니다. 실기기 UI와 10배속의 체감·프레임률은 별도 확인이 필요합니다.
