# RoboRelay v0.11.0 — 1레벨부터 레벨 재구성

## 변화

기존 10개 그림의 색상 반복과 동일한 정사각형/수량 패턴을 교체했다. 500개 데이터 모두 바뀌며 앱의 5개 슬롯·3행 대기열·로봇·트럭·아이템 조작·무제한 Easter egg는 유지한다.

- 그림 24종: 로봇, 트럭, 배터리, 톱니, 로켓, 크레인, 열차, 안전모, 굴착기, 공장, 드론, 화물선, 무전기, 로봇 강아지, 볼트, 풍차, 전구, 다리, 공구 상자, 위성 안테나, 지게차, 롤러, 자재 타워, 구조 로봇.
- 보드 윤곽 6종: 원형, 모서리 절단, 좁은 프레임, 계단 절단, 육각형, 전체 정사각형. 빈 외곽은 접근 경로에도 반영된다.
- 후반: 그림 위치·좌우 반전·배경 띠·색상 팔레트와 컨테이너 수량을 바꾼다. 이름은 24레벨마다 재사용하며 500개 모두 서로 다른 블록 데이터다.
- 초반 보드 폭: 28 / 32 / 36 / 40 / 44 / 48. 7레벨부터 48. 실제 블록 수는 빈 외곽에 따라 달라진다.
- 1레벨은 3색, 2~3레벨은 최대 4색, 4~8레벨은 최대 5색. 이후 팔레트 한도를 늘리며 그림에 쓰이지 않은 색상은 컨테이너에도 넣지 않는다.
- 3레벨부터 일부 보드에 열쇠, 4레벨부터 일부 보드에 봉인. 처음 봉인 조건은 18개, 이후 24~42개다. 열쇠는 빈 외곽과 닿은 실제 블록에 배치한다.
- 5/10의 배수 Hard/Super Hard, 13레벨 이후 미스터리 규칙 유지.
- 그림의 흩어진 내부 세부 색상 때문에 작은 컨테이너 여러 개가 일부만 회수하고 슬롯을 차지하는 로봇/무전기 보드는 원래 회수 순서를 지키는 4열 대기열을 사용한다. 다른 보드는 기존 색상 선택 함정과 묶음 순서 설계를 사용한다.

## 초기화 범위

사용자는 연결된 테스트 기기의 기존 기록을 지워도 된다고 승인했다. 새 APK 설치 후 이 기기의 앱 데이터만 초기화해 1레벨로 돌린다. 앱 코드에 다른 사용자의 저장 데이터를 자동 삭제하는 마이그레이션은 넣지 않는다.
