# Robot Flow v0.7.0 검증 — 2026-10-09

## 적용 범위

현재 동작은 [UI·게임 규칙](game-ui-v07.md)을 기준으로 합니다. 5개 작업 공간 복원, 컨테이너 출구·순차 출격, 4~5행 대기열과 연결 묶음, 즉시 슬롯 확장·셔플, 보드 터치 컬러 제거, 컨테이너 터치 꺼내기, 남은 작업 자동 3배속을 적용했습니다.

로봇 확대, 보드 위 장식 겹침 제거, 최대 3대 트럭 대기·앞자리 이동, 시간대 배경, 움직이는 메인, 난이도 표시·진입 안내, 위험 선택 테두리, 연승 보상과 완료 연출을 추가했습니다. 컨테이너 선택 취소는 없습니다.

## 자동 확인

- 최신 네이티브 엔진: 500개 레벨을 중장비 확률 0/1 각각 완주, 총 1,066 assertion 통과. 묶음 원자 선택·공간 부족·묶음 꺼내기·출격 원점·간격·자동 마지막 작업·트럭 대수·무제한 규칙 포함.
- 웹 Node 테스트 221개 통과. 이전 프로토타입 200개 레벨 회귀 테스트와 최신 500개 레벨 데이터 검증 포함.
- Android `assembleDebug lintDebug --offline --no-daemon` 성공. Lint 오류 0, 경고 15.
- `node scripts/build.mjs` 정적 웹 빌드 성공. localhost:5173에서 업데이트 확인. GitHub Pages 별도 배포 없음.

## 실제 화면 확인

- Samsung SM-S948N, 1440×3120: 5개 빈 작업 공간, 4행 대기열, 큰 숫자·아이템 아이콘, SUPER HARD와 연결 묶음, 보드와 분리된 트럭 도로 확인.
- 컨테이너 선택 후 출격·걷기·짐 운반 로봇, 3대 대기 트럭 및 적재 확인.
- 설정 제목 7회 터치로 무제한 On 후 보드 블록 터치 컬러 제거, 즉시 공간 확장·셔플 사용. 별도 확인창·색상 선택창 없음.
- 무제한 모드를 Off로 복원. 전후 저장 비교에서 신규 `streak=0` 필드 이외 차이 없음: current/unlocked 6, 코인 800, 아이템 3/2/3/3, 기록 1~5, 사운드·진동 설정 보존.
- 렌더 로그 관측 CPU 평균 15.00~16.31ms, 작업 로봇 4기, GL 오류 0. 모든 기기·최대 부하에서의 FPS 보장은 아닙니다.
- 웹 브라우저에서 5칸·4행·3대 트럭·선택 후 열 상승 확인.
