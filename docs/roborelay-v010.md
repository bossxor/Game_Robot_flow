# RoboRelay v0.10.0

## 화면·흐름

- 메인: 노란 운반 로봇이 보라색 LEVEL 표지판을 들고 있으며 현재 레벨을 표시한다.
- 메인과 플레이 상단: Normal / Hard / Super Hard를 색상 배지로 표시한다. 5의 배수 Hard, 10의 배수 Super Hard.
- 대기열: 최대 3행만 표시한다. 열의 앞 컨테이너가 출격하면 숨겨진 다음 컨테이너가 위로 올라온다. 빈 열 제거·중앙 정렬·빈 행 높이 축소는 유지한다.
- 기본 5개 작업 칸, 컨테이너 앞 순차 로봇 출격, 별도 공용 트럭, 1/2/3/4배속과 마지막 자동 10배속은 유지한다.
- 7색을 선명하게 변경하고 공사장 장식과 도로를 플레이 배경에서 제거했다. 보드 프레임과 작업 대상에 집중한다.
- 로봇 크기를 화면 폭 기준으로 확대했다. 레벨의 블록 개수에 따라 로봇 크기를 축소하지 않는다.
- 컨테이너 숫자는 연결 막대보다 앞에 표시한다. 네이티브 숫자는 Android sans-serif-condensed bold를 사용한다.

## 추가 퍼즐 규칙

- 열쇠: 열쇠가 놓인 블록을 회수하면 지정 색상의 모든 잠금 컨테이너가 해제된다. 잠금 상태에서는 일반 선택과 꺼내기 모두 불가능하다. 셔플해도 색상과 잠금 관계가 함께 이동한다.
- 봉인: 지정 색상의 블록을 24개 회수하면 중앙 6×6 봉인 구역이 공개된다. 상자에 남은 조건 수를 표시한다. 봉인 안쪽은 로봇과 컬러 제거로 직접 회수할 수 없다.
- 미스터리: 13레벨 이후 일부 깊은 컨테이너는 `?`로 표시한다. 해당 컨테이너가 선택 가능한 맨 앞이 되거나 두 색상의 블록을 모두 회수하면 색·수량이 공개된다. 선택 순서 규칙은 유지한다.
- 컬러 제거 아이템으로 정상 회수한 블록도 열쇠·봉인 조건에 반영한다.
- 6레벨부터 열쇠, 8레벨부터 봉인을 도입하며 10의 배수에는 함께 등장한다. 모든 레벨에 변칙을 넣지는 않는다.
- 기존 저장 키와 설정 제목 7회 터치의 무제한 아이템 Easter egg를 유지한다. 무제한을 꺼도 원래 보유 수량을 그대로 사용한다.

## 구현 범위

참고 앱의 플레이 흐름·화면·퍼즐 규칙을 로봇 테마로 구현한다. 하트·광고·일일 보상·기간 이벤트는 사용자 확인에 따라 제외한다. 참고 앱의 바이너리·아트 자산을 복사하지 않는다. 첨부 화면에 없는 전체 진행 규칙의 완전한 동일성은 보장하지 않는다.

## 검증

- 웹: `node --test`, 232개 통과. `node scripts/build.mjs` 정적 미리보기 빌드 통과.
- 네이티브: 5,075개 assertion 통과. 일반 운반원만 사용 / 중장비만 사용 각각 500개 전체 레벨 클리어. 미스터리 추가 규칙도 별도 통과.
- Android: 오프라인 assembleDebug / lintDebug 통과. lint 0 errors, 17 warnings.
- 연결된 SM-S948N에 v0.10.0 APK 업데이트 설치 성공.
- 웹 미리보기에서 메인, 난이도 배지, 5개 칸, 3행 대기열과 브라우저 오류 없음 확인.
- 잠금 해제 후 SM-S948N 실제 화면에서 메인 표지판·배지·5개 칸·3행 대기열, 연결 막대 위 숫자, 미스터리 `?` 표시를 확인했다.
- 10레벨 검증 모드에서 핑크 컨테이너 선택 차단, 보드 열쇠 회수 후 잠금 해제, 노란 블록 컬러 제거로 24개 조건 봉인 해제와 대기열 자동 승격을 확인했다.
- 실기기 검증에서 발견한 메인 로봇의 떨어진 장갑을 팔로 연결한 v0.10.1을 재설치했다. 진행·코인·수량·설정 XML은 설치 전과 동일하다.
- 검증 모드 종료 후 실제 9레벨 메인으로 복귀했다. 짧은 화면·다른 GPU 실기기와 장시간 플레이는 이번 확인 범위에 포함하지 않았다.
- Android 8.0 이상 개발 서명 APK. 스토어 출시용 서명·AAB 검증은 별도 작업이다.
